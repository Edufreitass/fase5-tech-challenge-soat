# Documentação

Este diretório reúne os materiais da entrega e a documentação de apoio.

## Índice

- [`deliverables/`](deliverables/): enunciado oficial, relatórios de arquitetura, segurança e SAGA, além do PDF consolidado.
- [`deliverables/src/`](deliverables/src/): fontes HTML dos PDFs. Para regenerá-los (exige Google Chrome): `python3 docs/deliverables/src/build.py`.
- [`diagrams/`](diagrams/): diagramas editáveis em Draw.io e suas exportações PNG.

Para entender os requisitos e como foram atendidos, comece pelo [README da raiz](../README.md). Para implantar ou executar testes, ele também contém os comandos e pré-requisitos.
